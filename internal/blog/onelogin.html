Poppin One Login

Coming Soon — One login for all Poppin services

We're excited to announce Poppin One Login — a unified authentication system that will allow Poppin Staff to sign in once and access all Poppin services seamlessly.

What is Poppin One Login?

Poppin One Login is our new single sign-on (SSO) solution designed specifically for Poppin Staff. Instead of managing separate credentials for each internal service, you'll use one account to access everything.

Coming Soon: This feature is currently in development and will be rolled out to all staff members in the near future.

Benefits

  • One set of credentials — Use the same email and password across all Poppin services
  • Faster access — No more switching between different login screens
  • Enhanced security — Centralized authentication with improved security measures
  • Seamless experience — Move between services without re-authenticating
  • Easier management — Update your password once, and it applies everywhere

Services That Will Use Poppin One Login

Once launched, Poppin One Login will be the authentication method for:

  • Internal Fund Sheet
  • Chocoluxe Money Management
  • Other internal tools and services

What You Need to Do

For now, continue using your existing login methods for each service. When Poppin One Login is ready, we'll provide clear instructions on how to migrate your account and start using the new system.

Questions?

If you have questions about Poppin One Login, please contact your IT administrator. We'll share more details as we get closer to the launch date.
